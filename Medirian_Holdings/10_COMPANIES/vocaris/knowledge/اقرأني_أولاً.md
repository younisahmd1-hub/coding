# اقرأني أولاً — كيف تشغّل مجلد Vocaris مع Claude Code

هذا المجلد فيه **كل شي** عن Vocaris: المعرفة، الاستراتيجية، حالة الإعلانات،
حالة الوكيل، وفريق من ١٠ وكلاء جاهزين يشتغلون جواه.

---

## الخطوة ١ — حطّ المجلد على جهازك

فكّ ضغط الملف، وحطّ مجلد `Vocaris` في مكان ثابت ما تنساه. مثلاً:

```
C:\Users\youni\Vocaris
```

مهم: لا تغيّر مكانه بعد هيك، ولا تفكّ أي شي من جواه.

---

## الخطوة ٢ — افتح Claude Code داخل هذا المجلد بالذات

في تطبيق Claude على الكمبيوتر:
1. افتح جلسة Claude Code جديدة.
2. لمّا يسألك عن المجلد (folder)، اختار `C:\Users\youni\Vocaris`.
3. أكّد.

**ليش داخل المجلد بالذات؟** لأن الوكلاء والأوامر مخزّنين جواه في مجلد مخفي
اسمه `.claude`. لو فتحت Claude Code في مكان ثاني، ما رح يشوفهم.

---

## الخطوة ٣ — اكتب كلمة واحدة

```
/room
```

رح يعرض لك: الفريق، وين واقف مشروعك، وشو الخطوة التالية.

---

## الخطوة ٤ — املأ ملف واحد قبل أي شي

افتح `data/ICP.md` واكتب فيه:
- **مدينة واحدة**
- **حيّ واحد**
- **قطاع واحد** (مثلاً: صالونات)

كل الوكلاء يقرأون هذا الملف قبل أي مهمة. لو تركته فاضي، رح تطلع كل المخرجات
عامة وما تنفع. هذا أهم سطر في المجلد كله.

---

## الأوامر الأربعة الجاهزة

| تكتب | يصير |
|---|---|
| `/room` | يعرض الفريق + حالتك + الخطوة التالية |
| `/new-prospect صالون كذا` | يبحث عن المصلحة، يأهّلها، يجهّز الديمو والرسائل |
| `/today` | قائمة اليوم: مين تتواصل معه ومين تتابعه |
| `/week-review` | مراجعة الأرقام: وين تخسر العملاء وشو تصلح |

---

## ماذا يوجد في كل مجلد

| المجلد/الملف | ما فيه |
|---|---|
| `CLAUDE.md` | القواعد — Claude يقرأه تلقائياً كل جلسة |
| `VOCARIS_MASTER_KNOWLEDGE.md` | **كل معرفة المشروع في ملف واحد** — ابدأ من هنا |
| `data/` | الملفات اللي تعدّلها أنت: العميل المثالي، الرسائل، الاعتراضات، جدول العملاء |
| `docs/` | ملفات حالة المشروع الأصلية (الإعلانات، الوكيل، المهارات) |
| `demos/` | ملف لكل عميل محتمل تجهّز له ديمو |
| `outbox/` | المسودات الجاهزة للإرسال — **أنت** اللي ترسلها بيدك |
| `assets/` | حطّ هون فيديوهات الإعلانات والصور (فاضي حالياً) |
| `.claude/` | الوكلاء والأوامر — لا تلمسه |

## الفيديوهات الموجودة على جهازك

هالملفّين موجودين عندك وما قدرت أجيبهم لأن الجهاز غير موصول بالمحادثة.
انسخهم بيدك إلى مجلد `assets/`:

```
C:\Users\youni\Downloads\Vocaris_Ad1_2AM.mp4
C:\Users\youni\Downloads\Vocaris_Ad_v6.mp4
```

ولو عندك مجلدات ثانية فيها ملفات Vocaris (مثل مجلدات إعلان C1 أو البلايتات)،
انسخها جوّا `assets/` كمان — وبعدها قول لـ Claude Code «رتّب لي مجلد assets»
وهو يرتّبها ويحدّث ملف المعرفة.

---

## ثلاث قواعد بنيت عليها الغرفة

1. **ما حد يرسل بدون موافقتك.** الرسائل تُكتب في `outbox/` وأنت ترسلها. أبطأ،
   بس رسالة واحدة سيئة من بوت تحرق الرقم كله.
2. **الديمو الشخصي قبل الرسالة.** ما نرسل لحد قبل ما يكون جاهز رابط يتصل عليه
   ويسمع الوكيل يقول اسم مصلحته.
3. **ممنوع اختراع رقم أو وعد مطلق.** «كل مكالمة تُجاب» مشيلة — ما نقدر نثبتها.
   البديل: «جرّبه شهر وشوف كم حجز جاك.»

---

## المزامنة مع محادثاتك على claude.ai

كل ساعة، Claude ينقل الجديد من محادثات مشروع Vocaris إلى هذا المجلد تلقائياً
(لازم يكون الكمبيوتر شغّال وتطبيق Claude مفتوح).

- الجديد ينزل في `docs/from_chats/`
- ملف `SYNC_STATE.md` يقول لك متى آخر مزامنة وشو وصل
- لمّا تفتح Claude Code وفي شي جديد، اكتب:

```
/sync
```

وهو يدمجه في كل الملفات، ولو في تعارض بيسألك.
